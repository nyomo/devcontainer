# VS Code用のDockerで何でもやる環境

- AI(codex)をコンテナ内で自由に作業させる環境を作りたい
- AIが自由にやりすぎて変なサイトにアクセスしてるのに気づかない状況はやめたい
  - proxy経由でインターネットに出すとログが出る

# 使い方

- このリポジトリをcloneする
- VS Codeで開く(VS Codeの準備については後で書く)
-- Dev Containers拡張が必要
- このフォルダをVS Codeで開く
- ctrl + shift + p で拡張メニューを出す
- `>dev containers open folder in container` を選ぶ
